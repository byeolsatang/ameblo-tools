# Ameblo Tools

アメブロを書くときに使う、個人用の小さな便利ツール集です。

## ツール

- [インスタ埋め込みメーカー](https://byeolsatang.github.io/insta-embed-maker/)
- [アメブロ装飾タグメーカー](https://byeolsatang.github.io/blog-deco-maker/)

## 合言葉

`index.html` 内の次の行を書き換えると変更できます。

```js
const PASSPHRASE = 'kira0309';
```

これは GitHub Pages 上で動く簡易ガードです。公開リポジトリなので、本格的な認証ではありません。

## GitHub Pages

Repository の **Settings → Pages** で、`main` ブランチの `/ (root)` を公開元にしてください。
